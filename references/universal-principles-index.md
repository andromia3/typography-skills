# Universal Principles of Typography — retrieval index

All 100 principles from Elliot Jay Stocks, *Universal Principles of Typography*
(Rockport, 2024), with the skill in this pack that owns each area.

The spec that produced this pack calls this book "a retrieval-friendly reference
index." This is that index: use it to find which principle covers a question, then
load the routed skill for the decision procedure. The principle titles are Stocks'
own; the routing is this pack's.
